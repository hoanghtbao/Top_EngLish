# Top_EngLish

Nền tảng trực tuyến hỗ trợ học tiếng Anh từ vựng, ngữ pháp, luyện tập (Spaced Repetition & Quiz), theo dõi tiến độ cá nhân và trợ lý AI thông minh.

## Cấu trúc dự án

- **`top-english-backend/`**: Hệ thống Backend xây dựng bằng NestJS, Mongoose (MongoDB), TypeScript, JWT Authentication.
- **`top-english-frontend/`**: Ứng dụng Frontend xây dựng bằng Next.js (App Router), React 19, Tailwind CSS, Shadcn UI.

## Bắt đầu

### Backend
```bash
cd top-english-backend
npm install
npm run start:dev
```

### Frontend
```bash
cd top-english-frontend
npm install
npm run dev
```
